## 1. 요청 개요

### 1.1 목적

본 요청서는 **글로벌 엔지니어링 센터(GEC) B동**을 대상으로 건물 시맨틱 데이터 모델(온톨로지)을 구축하기 위해 필요한 건물 설비 및 운영 데이터의 제공을 요청드리기 위함입니다.

구축되는 온톨로지는 국제 표준인 Brick Schema(RDF 기반 건물 메타데이터 표준)에 따라 건물의 **위치(공간), 장비, 센서/제어 포인트, 시스템** 간의 관계를 구조화하며, 스마트빌딩 데이터 분석 및 에너지 최적화의 기반 데이터로 활용됩니다.

| 항목 | 내용 |
|------|------|
| 대상 건물 | GEC B동, 서울특별시 강동구 상일로6길 26 (상일동 500) |
| 활용 목적 | 건물 데이터 표준화, 에너지 최적화, 디지털트윈 기반 구축 |
| 데이터 표준 | Brick Schema 1.3+ (국제 건물 시맨틱 메타데이터 표준) |

### 1.2 현재 진행 상황

공개 자료 기반의 리서치를 통해 전체 데이터의 약 **60%를 확보**하였으며, 나머지 40%는 내부 자료를 통해서만 확보 가능합니다.

| 분야 | 확보율 | 비고 |
|------|:------:|------|
| 건물 기본정보 | 81% | 구조, 규모, 층수, 인증 등 대부분 확보 완료 |
| HVAC/공조 시스템 | 38% | 시스템 유형은 확인, **장비 상세 미확보** |
| BMS/BAS 시스템 | 41% | 인증/플랫폼은 확인, **포인트 리스트 미확보** |
| 전기/소방/보안 | 33% | 대부분 미확보 |
| 에너지/ESG | 70% | ESG 보고서 기반 확보, **실운영 데이터 미확보** |

### 1.3 이미 확보된 정보

아래 정보는 공개 자료에서 이미 확인 완료되었으므로 별도 제공이 불필요합니다.

- 건물 규모: 전체 연면적 186,023m², 대지면적 27,604m², 건축면적 14,506m²
- 구조: RC(철근콘크리트), 지상15층/지하4층, 승강기 37대, 주차 1,403대(자주식)
- HVAC 방식: UFAD(18~20°C) + 칠드실링(16°C) + 복사난방 3중 복합
- 외피: 서향 이중외피(DSF), 가변형 외부 라이트셀프
- 인증: G-SEED 최우수(2012), 에너지효율 1등급(287.4 kWh/m²), LEED Gold(NC v2.2, 45/69점), IBS 1등급
- 에너지 절감율: 일반 건물 대비 약 40% (HOK 설계 기준)

## 5. 데이터 활용 목적 및 기대 효과

### 5.1 활용 목적

제공받은 데이터는 국제 표준(Brick Schema)에 따라 GEC B동의 건물 데이터 모델(온톨로지)로 구축됩니다. 이 모델은 건물 내 모든 공간, 장비, 센서, 시스템 간의 관계를 구조화하여, 스마트빌딩 애플리케이션의 데이터 기반으로 활용됩니다.

### 5.2 기대 효과

| 효과 | 설명 |
|------|------|
| **데이터 표준화** | 건물 설비/센서 데이터를 국제 표준에 맞게 구조화 |
| **상호운용성** | 다양한 빌딩 애플리케이션 간 데이터 교환 가능 |
| **에너지 최적화** | 에너지 사용 패턴 분석 및 최적화 기반 마련 |
| **디지털트윈** | 향후 디지털트윈 플랫폼 연계 시 시맨틱 데이터 레이어 역할 |
| **ESG 보고** | 건물 단위 탄소 배출/에너지 사용 추적 체계 구축 |

### 5.3 데이터 보안

- 제공받은 모든 데이터는 **본 프로젝트 목적으로만** 사용합니다.
- 외부 공개 또는 제3자 제공을 하지 않습니다.
- 보안 등급이 있는 자료는 해당 등급에 따라 취급합니다.
- 필요 시 **NDA(비밀유지계약)** 체결 가능합니다.
