# GEC B동 Brick Schema 온톨로지 구축을 위한 데이터 요청서

**문서번호:** BEES-REQ-2026-001
**작성일:** 2026년 2월 10일
**프로젝트:** 삼성물산 GEC B동 Brick Schema 기반 건물 온톨로지 구축
**대상 건물:** 글로벌 엔지니어링 센터(GEC) B동, 서울특별시 강동구 상일로6길 26 (상일동 500)

---

## 1. 요청 배경

### 1.1 프로젝트 개요

본 프로젝트는 삼성물산 GEC B동을 대상으로 **Brick Schema(RDF 기반 건물 시맨틱 메타데이터 표준)**에 따른 온톨로지를 구축하는 것을 목표로 합니다. Brick Schema는 건물의 위치(Location), 장비(Equipment), 센서/제어 포인트(Point), 시스템(System) 간의 관계를 표준화된 형식으로 기술하며, 이를 통해 스마트빌딩 데이터의 상호운용성과 분석 가능성을 확보합니다.

### 1.2 현재 진행 상황

공개 자료 기반의 웹 리서치(1~3차 + Phase 1)를 통해 전체 데이터의 약 **60%를 확보**하였습니다.

| 분야 | 확보율 | 비고 |
|------|:------:|------|
| 건물 기본정보 | 81% | 구조, 규모, 층수, 인증 등 대부분 확보 |
| HVAC/공조 시스템 | 38% | 시스템 유형은 확인, **장비 상세 미확보** |
| BMS/BAS 시스템 | 41% | 인증/플랫폼 확인, **포인트 리스트 미확보** |
| 전기/소방/보안 | 33% | 대부분 미확보 |
| 에너지/ESG | 70% | ESG 보고서 기반 확보, **실운영 데이터 미확보** |

### 1.3 이미 확보된 정보 (참고)

아래 정보는 공개 자료에서 이미 확인 완료되었으므로, 별도 제공이 불필요합니다.

- 건물 규모: 전체 연면적 186,023m², 대지면적 27,604m², 건축면적 14,506m²
- 구조: RC, 지상15층/지하4층, 승강기 37대, 주차 1,403대
- HVAC 방식: UFAD(18~20°C) + 칠드실링(16°C) + 복사난방 3중 복합
- 외피: 서향 이중외피(DSF), 가변형 외부 라이트셀프
- 인증: G-SEED 최우수, 에너지효율 1등급(287.4 kWh/m²), LEED Gold(NC v2.2, 45점), IBS 1등급
- 에너지 절감율: 일반 건물 대비 약 40% (HOK 설계 기준)

## 4. 데이터 활용 목적

### 4.1 Brick Schema 온톨로지 구축

제공받은 데이터는 아래와 같이 Brick Schema 표준에 따라 모델링됩니다.

```
[예시: B동 5층 내부존의 온톨로지 구조]

bldg:GEC_Tower_B_5F          a  brick:Floor
bldg:GEC_B_5F_Interior_Zone  a  brick:HVAC_Zone
bldg:GEC_B_AHU_UFAD_01       a  brick:Air_Handling_Unit
bldg:GEC_B_5F_INT_ZAT        a  brick:Zone_Air_Temperature_Sensor
bldg:GEC_B_5F_INT_Diffuser   a  bees:Floor_Diffuser

관계:
  bldg:GEC_B_5F_Interior_Zone  brick:isPartOf       bldg:GEC_Tower_B_5F
  bldg:GEC_B_AHU_UFAD_01       brick:feeds          bldg:GEC_B_5F_Interior_Zone
  bldg:GEC_B_5F_INT_ZAT        brick:isPointOf      bldg:GEC_B_5F_Interior_Zone
  bldg:GEC_B_5F_INT_Diffuser   brick:isFedBy        bldg:GEC_B_AHU_UFAD_01
```

### 4.2 기대 효과

| 효과 | 설명 |
|------|------|
| 데이터 표준화 | 건물 설비/센서 데이터를 국제 표준(Brick Schema)에 맞게 구조화 |
| 상호운용성 | 다양한 빌딩 애플리케이션 간 데이터 교환 가능 |
| 분석 기반 | 에너지 최적화, 이상 감지, 공간 활용 분석의 데이터 기반 마련 |
| 디지털트윈 | 향후 디지털트윈 플랫폼 연계 시 시맨틱 데이터 레이어 역할 |
| ESG 보고 | 건물 단위 탄소 배출/에너지 사용 추적 체계 구축 |

### 4.3 데이터 보안

- 제공받은 모든 데이터는 본 프로젝트 목적으로만 사용합니다
- 외부 공개 또는 제3자 제공을 하지 않습니다
- 보안 등급이 있는 자료는 해당 등급에 따라 취급합니다
- 필요 시 NDA(비밀유지계약) 체결 가능합니다
