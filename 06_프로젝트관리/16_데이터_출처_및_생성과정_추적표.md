# GEC B동 온톨로지 데이터 출처 및 생성 과정 추적표

> **목적:** 134건의 데이터 항목 각각이 어디서 수집되었고, 수집할 수 없었던 것은 어떤 과정을 거쳐 생성했는지를 기록
> **활용:** 다른 건물에 동일한 온톨로지를 구축할 때, 이 표를 따라가며 동일하게 데이터를 수집/생성
> **온톨로지:** GEC_B_Ontology.ttl v1.7 (2,938줄, 2,024 트리플)
> **전체:** 134건 = confirmed 75건 + estimated 45건 + inferred 14건

## 범례

| 기호 | 의미 |
|------|------|
| **C** | confirmed — 공식 문서에서 직접 확인한 데이터 |
| **E** | estimated — 계산/벤치마킹/논문으로 추정한 데이터 |
| **I** | inferred — 법규/규정에서 역추론한 데이터 |
