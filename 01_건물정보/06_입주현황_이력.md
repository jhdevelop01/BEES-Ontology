# 삼성물산 GEC B동 - 입주 현황 및 이력

## 주요 연혁

| 연도 | 내용 |
|------|------|
| 2009년 9월 | GEC 건물 착공 |
| 2011년 5월 | 상량식 |
| 2012년 4월 | GEC 준공, 삼성엔지니어링 강동구 상일동 GEC 신사옥으로 이전 |
| 2015년 | 삼성물산 건설부문, 서초 삼성타운 → 판교 알파돔시티 이전 |
| 2018년 3월 16일 | 삼성물산 건설부문, 판교 사옥 → GEC B동 이전 입주 ('상일동 시대' 개막) |
| 2023년 | 삼성물산-삼성E&A 임대계약 갱신 (5년 연장, 임대료 34% 인상) |

## 현재 입주사

| 입주사 | 비고 |
|--------|------|
| 삼성E&A (구 삼성엔지니어링) | 본사 (A동+C동), 건물 소유주, 약 2,700명 |
| 삼성물산 건설부문 | **B동** 임차 (2018.3~), 약 **2,000명** |

> **참고:** 삼성엔지니어링 경영 악화(자본잠식)로 인원 감소 → B동 공실 발생 → 삼성물산 건설부문이 경영효율화 차원으로 임차.
> 이전 경로: 서초 삼성타운 → 판교 알파돔시티 → 상일동 GEC B동.
