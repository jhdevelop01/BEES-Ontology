# 삼성물산 GEC B동 - 설비 및 인프라

## 승강기 (엘리베이터)

| 항목 | 내용 |
|------|------|
| 총 대수 | 37대 (GEC 전체) |
| 승용 엘리베이터 | 32대 |
| 비상/화물용 엘리베이터 | 5대 |

> **참고:** 37대는 GEC 단지 전체 기준이며, B동 단독 배정 대수는 미확인.
> B동 특이사항: **4층과 13층이 없음** (건너뛰는 층).

## 주차장

| 항목 | 내용 |
|------|------|
| 총 주차대수 | 1,403대 |
| 주차 방식 | 자주식 (1,403대 전량) |
| 위치 | 지하 (지하 4층 구조) |

## 기준층 정보

| 항목 | 내용 |
|------|------|
| 기준층 임대면적 | 5,471.54 m² |

> **참고:** 이 면적이 GEC 전체 기준층인지, 특정 동 기준인지 미확인.

## 전기 설비

| 항목 | 확인 상태 | 내용 |
|------|-----------|------|
| 전력 모니터링 | **확인** | 자동화 디지털 네트워크 시스템이 에너지 비용까지 모니터링 |
| 수전 용량 (kVA) | 미확인 | 연면적 186,023 m² 규모, 특고압 22.9kV 2회선 이상 수전 추정 |
| 수배전 설비 구성 | 미확인 | - |
| 분전반 구성 | 미확인 | - |
| 비상발전기 | 미확인 | 이 규모에서 1,500~2,500kW급 2~3대 이상 추정 |
| UPS | 미확인 | 지능형건축물 1등급 인증에 UPS 필수적 |
