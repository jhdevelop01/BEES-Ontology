## 4. Neo4j 임포트 시 활용

comment는 Neo4j에서 노드 프로퍼티로 변환됩니다:

```
[TTL]
bldg:Chiller_1 rdfs:comment "원심식 터보 냉동기 800RT..."

[Neo4j]
(:Chiller {uri: "...Chiller_1", label: "B동 칠러 #1", comment: "원심식 터보 냉동기 800RT..."})
```

LLM이 Cypher 쿼리 결과에서 `comment` 프로퍼티를 읽어 풍부한 자연어 답변 생성에 활용합니다.

### 활용 예시

```
사용자: "칠러 1번이 뭐야?"

Cypher: MATCH (c:Chiller) WHERE c.label CONTAINS '칠러 #1' RETURN c.label, c.comment

LLM 답변: "칠러 1번은 800RT 원심식 터보 냉동기로, 7°C 냉수를 생산하여
          각 층 AHU와 FCU에 공급합니다."
```
