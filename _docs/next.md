## 개선 가능 항목 (우선순위순)

### 1. Zone 센서 시뮬레이션 (Server C)
현재 Zone 센서(ZAT/ZAH/CO2)는 Server C에서 시뮬레이션하지 않아 SSE에 없음.
Room 센서값은 장비 평균(RAT/RAH/CO2)에서 상속됨 — Zone별 독립 센서 시뮬레이션 추가 시 Room별 차별화 가능.

| 항목 | 내용 |
|------|------|
| 대상 | ZAT_XF_Int, ZAH_XF_Int, CO2_XF_Int (25쌍) |
| 방법 | Server C neo4j_loader에 Zone 센서 포인트 인식 추가 |
| 효과 | Room별 온도/습도/CO2 차별화 |

### 2. 저층(1F/2F/3F) 및 지하(B1F~B4F) 센서 데이터
현재 AHU 없는 층은 온도/습도/CO2가 "—"으로 표시됨.
- 1F(로비): FCU 기반 온도 추정 가능
- B2F~B4F(주차장): CO 센서 + 환기팬 상태만 유의미
- 별도 센서 포인트 추가 또는 "해당 없음" 표시 개선

### 3. Room 평면도 시각화
현재 Room은 리스트/테이블 형태로만 표시. 추후 층별 평면도(SVG/Canvas)와 결합하면 시설 관리 UX 대폭 향상.

| 단계 | 내용 |
|------|------|
| 3-A | SVG 평면도 템플릿 제작 (5F 시범) |
| 3-B | Room 영역 클릭 → 센서 팝업 |
| 3-C | 온도 기반 색상 오버레이 |

### 4. Floor Power Meter InfluxDB 연동
Floor_Power_XF_kW / Floor_Energy_XF_kWh 포인트가 InfluxDB에 저장되면 시계열 분석 가능.
- 일/주/월별 층간 에너지 비교 차트
- EUI 계산 정밀화 (현재 추정 기반)
